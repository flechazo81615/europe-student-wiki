## 3. 住宿及生活區域

### 住宿參考價格

根據 Generalitat de Catalunya（加泰隆尼亞政府）2026 年生活成本參考資料，Barcelona 的住宿價格約為每月 €500–700。

這是參考價格，實際租金會因住宿類型、地點、房間條件及租約而有所不同。

### 住宿規劃提醒

- 提早比較學生宿舍、合租房間及私人租屋。
- 確認租金是否包含水電、暖氣及網路。
- 注意押金、租期及其他額外費用。
- 不應只依照參考價格估算自己的實際住宿預算。

## 4. 飲食與日常採買

### 食品及日常消費參考

加泰隆尼亞政府 2026 年參考價格：

| 項目 | 參考價格 |
|---|---:|
| 法國麵包 | €1 |
| 雞肉 | €9／公斤 |
| Pizza | €3.50／份 |
| 雞蛋 | €3.50／12 顆 |
| 生理用品 | €4／月 |
| 咖啡 | €1.80 |
| 汽水 | €1.70 |
| 平日套餐 | €15–18 |

### 日常生活建議

- 平日可留意餐廳的 Menú del día（每日套餐）。
- 食品採買與外食費用應分開記錄。
- 上述價格為參考值，實際價格會隨商店及地點而變化。

## 5. 預算及消費

### 交通費參考

根據加泰隆尼亞政府 2026 年參考價格：

| 票券種類 | 參考價格 |
|---|---:|
| 地鐵／公車單程票 | €2.80 |
| 10 次搭乘票 | €12.55 |
| T-usual 月票 | €22 |

購買前應確認票券適用區域、有效期間及個人資格。

### 其他生活支出

| 項目 | 參考價格 |
|---|---:|
| 手機及 Wi-Fi | €35–40／月 |
| Bicing 公共自行車 | €50–60／年 |
| 汽油 | €2／公升起 |

### 預算規劃提醒

1. 住宿通常是需要優先估算的支出。
2. 依照實際搭乘頻率選擇交通票券。
3. 將飲食、手機網路及娛樂費用分開記錄。
4. 預留額外支出，不要將參考價格視為固定預算。
